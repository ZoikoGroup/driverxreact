| DEFECT-18 | **Blocker** | existing site (not Drixo) | **The dashboard's authorization is client-side.** `app/dashboard/MyAccount.tsx` and `app/dashboard/add-device/page.tsx` read the user's email from `localStorage`, then call the BeQuick carrier API directly from the browser with the single global admin token (`app/utils/dasdbeQuickApi.js`): look up a subscriber by email or id, read payment methods, orders, bills and lines, and create lines.
