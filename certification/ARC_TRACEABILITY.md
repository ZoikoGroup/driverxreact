# Architecture test matrix traceability (Doc 08 section 17, ARC-01..30)

Status words: **pass** (automated evidence in this repo), **partial** (evidence with a stated limit),
**n/a** (nothing exists to test yet), **not proven**, **fail**.
Test files are in `tests/drixo/`. "prod" means run against `next start` (production mode).

| ID | Required pass condition | Status | Evidence and limits |
|---|---|---|---|
| ARC-01 | Exactly five public routes; no privileged route | **pass** | production build output lists exactly the five `/api/v1/drixo/public/*` routes; `api-contract` asserts `/activate /billing /subscriber /handoff /payment /fleet/lines` are 404; `adversarial` shows other methods rejected |
| ARC-02 | Guest cannot read subscriber or fleet record | **pass** | no code path or supplier integration exists to do so; `flow-contract` sends 12 protected requests plus forged-role and "I am the account owner" prompts, all answered `AUTH_GATE` with no data. Limit: this proves the absence of a path, not behavior of a future integration |
| ARC-03 | Wrong CSRF, cookie, Origin rejected | **pass** | `api-contract` (missing/wrong CSRF 403, wrong Origin 403, missing Origin 403, no cookie 404), repeated in prod; `ops-e2e` (non-allowlisted Origin blocked in production) |
| ARC-04 | SessionId alone grants no authority | **pass** | `api-contract`: sessionId without cookie 404; another session's id with my cookie 404; my CSRF on another session 403 |
| ARC-05 | Stale contextVersion returns 409 | **pass** | `api-contract` (stale 409, state unchanged, 5 concurrent turns one wins); `ops-e2e` (8 concurrent turns across **two instances**, exactly one wins) |
| ARC-06 | Forged/reused quick-reply blocked | **pass** | `flow-contract`: unknown option, option from another flow, consumed option, injected extra field, new text invalidates old options |
| ARC-07 | Idempotent retry yields one turn | **pass** | `api-contract`; `ops-e2e` (same key replayed across two instances returns the same turnId) |
| ARC-08 | Identical key + changed body returns 409 | **pass** | `api-contract` (sessions and turns) |
| ARC-09 | Model answer has no unapproved URL | **pass** (mock provider) | every action link comes from the registry (`flow-contract`); citation URLs are https and allowlisted (`kb-e2e`); model text containing a URL, bare domain, email, markup or markdown is rejected by the output gate and replaced by approved text (`model-e2e`: 6 cases), and the model has no field with which to supply a link. Limit: proven against a mock that emits those attacks, not against the real model |
| ARC-10 | Private/revoked knowledge never cited | **pass** | `db.test` (draft/in-review/revoked/expired/conflict/hold excluded from the view); `kb-e2e` (served answers only from approved revisions, 40 scenarios) |
| ARC-11 | Source revoked mid-flight fails safe | **pass** | `kb-e2e` (dev server, fault hook) and `model-e2e` in **production mode**: the source is revoked while the provider call is in flight, the model answer is discarded, `NO_SOURCE`, `kb_revoked_or_conflict` recorded |
| ARC-12 | Price conflict returns NO_SOURCE | **pass** | `kb-e2e`/`db.test`: an open conflict suppresses the revision; no pricing article is approved so price questions stay `NO_SOURCE`. Limit: real conflict detection (comparing two sources' claims) is a human workflow (`conflict-open`), not automated |
| ARC-13 | Secrets blocked before model call | **pass** (with known gaps) | secrets are detected before any answer logic (`flow-contract`, `adversarial`: 20 obfuscations) and `model-e2e` proves the provider is never called for secret, card, protected, emergency, human, flow and unanswerable traffic, and that the request body contains no cookie, CSRF token, session id or IP. 6 evasions remain undetected by design of a regex screen (see DEFECT-7) |
| ARC-14 | No raw transcripts in DB/logs | **pass** | `db.test` schema lint; `persist-e2e` dumps every guest table after a conversation and finds no typed text, answer text, cookie or CSRF token; `ops-e2e`/`model-e2e` assert no question text, model output, key or identifier in any server log line. Limit: covers the app's own logs and the database, not platform/proxy/APM logging or the provider's own retention (D-04) |
| ARC-15 | PostgreSQL roles least privilege | **pass** (engine-level) | `db.test` with `SET ROLE`: BFF reads the view only, cannot read kb tables, publish, delete sessions or change flags; publisher cannot read guest data or write tables directly. Limit: roles tested on PGlite; real IAM/login provisioning not done |
| ARC-16 | Expiration and end state invalidate session | **pass** | `expiry-e2e` (idle expiry, absolute expiry even while active, activity extends idle); `api-contract`/`ops-e2e` (end revokes across instances) |
| ARC-17 | Redis loss does not bypass checks | **pass** | `ops-e2e`: Redis killed, valid/forged/no-cookie requests all non-200 (503), responses bounded and generic, automatic recovery, old sessions honestly gone |
| ARC-18 | Model outage retains safe fallback | **pass** (mock provider) | `model-e2e`: provider 500, 429, hang (bounded by the timeout), refusal and malformed output all fall back to the approved article text; the breaker opens and closes; the budget caps stop spend; `model-off` returns to approved text with no deploy |
| ARC-19 | Failed commit not shown as success | **pass** | `ops-e2e`: with Redis down a turn returns 503, never a fabricated reply. Limit: no separate test for a failure between CAS and response |
| ARC-20 | Rate limit and Retry-After correct | **pass** | `api-contract` (per-session burst returns 429 with Retry-After and `retryable: true`) in prod. Limit: limits are my defaults pending SRE; edge/WAF limits are not tested here |
| ARC-21 | WF-00 to WF-10 mobile/desktop covered | **partial** | in a real browser (`a11y.mjs`, `ui-behaviour.mjs`: launcher, welcome at 1280/390/320, connection flow with quick replies, support result, auth gate, secret warning, privacy view, end confirmation, error with retry, **offline state**, over-length error, rephrase/escalation); all six flows at API level (`flow-contract`). Not covered: the other five flows end-to-end in a browser, 360/430 widths explicitly, real devices |
| ARC-22 | Keyboard + screen reader / focus | **partial** | keyboard order, visible focus, Escape/focus return, dialog naming, live region, axe over 10 states: pass (`a11y`). **Screen-reader testing not done.** Two axe "needs review" contrast items to verify manually |
| ARC-23 | Parked-only message on first use | **pass** | `a11y`: the safety notice is present, exposed as a note, and first in reading order after the header |
| ARC-24 | No false live-agent status | **pass** | responses and flows assert no ticket number, ETA, "agent connected", "24/7" (`flow-contract`, `kb-e2e` invariants over all 40 scenarios). **Open issue:** the existing support page URL contains "24-7" (D-05) |

| ARC-26 | Canary and rollback demonstrated | **pass** (test stack) | `ops-e2e`: rollout, kill, restore reach both instances within the flag TTL without deploy; kill survives a DB outage; widget visibility follows it in a real browser.
